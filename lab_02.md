# Ответы на вопросы и задания

### 1. Как определить, сколько параметров пользователь передал в скрипт при запуске?
Количество переданных параметров хранится во встроенной переменной **`$#`**.
*Пример:* `if [ "$#" -ne 3 ]; then ... fi`

### 2. Какие недостатки есть у вашего подхода к определению производительности в FLOPS?
- Интерпретатор `bc` выполняет вычисления на программном уровне, а не напрямую на регистрах процессора. Это замедляет тест.
- Команда `echo "scale=10; ..." | bc`. На каждый шаг цикла тратится время на создание процессов, передачу данных и перенаправление потоков в `/dev/null`.
- Тест нагружает только один поток одного логического ядра, игнорируя общую многопоточную мощность процессора.

### 3. Сбор данных о CPU через конвейер без промежуточных файлов
Реализовать сбор данных в один конвейер можно, объединив нужные утилиты в скобки `{ ... }` или `( ... )`, и передав их общий вывод в `grep`:

```bash
(uname -a && cat /etc/os-release && lscpu && sudo dmidecode && lspci -nnv) | grep -iE "linux|pretty_name|model name|cpus|cache|mem:|product|bios"
```

**Аргументы:**

| Подход | За | Против |
| :--- | :--- | :--- |
| С промежуточным файлом|Данные собираются один раз. Можно вытаскивать информацию сколько угодно раз разными командами, не нагружая повторно систему. | **Засорение диска:** создаются временные файлы в системе. |
| UNIX-way |Данные обрабатываются в оперативной памяти без записи на жесткий диск. | Если в конвейере пропустить ключевое слово для `grep`, придется заново запускать утилиты, например `dmidecode` и `lspci`. |

### 4. В чём разница между утилитами modprobe и insmod?
*   `insmod` — низкоуровневая утилита, которая загружает строго один указанный файл модуля (нужно писать полный путь к файлу `.ko`).
*   `modprobe` — высокоуровневая утилита. Ей пишется только короткое имя модуля (например, `e100`). Она сама находит файл, автоматически проверяет дерево зависимостей и загружает все связанные драйверы в правильном порядке.

### 5. Как определить, поддерживает ли процессор аппаратное шифрование AES?
Нужно проверить флаги процессора в файле `/proc/cpuinfo`. Если в списке флагов есть слово `aes`, значит процессор поддерживает эту функцию.  

```bash
grep -i "aes" /proc/cpuinfo
```

### 6. Откуда команда modprobe узнала, где расположен файл модуля e100?
Она ищет модули в системной директории `/lib/modules/$(uname -r)/`.  
`modprobe` не сканирует папки каждый раз, а читает заранее сгенерированный бинарный файл зависимостей `modules.dep.bin`, который создается в этой же папке утилитой `depmod`.

### 7. В каких форматах утилита lshw может генерировать отчёты и для чего они нужны?
*   Для анализа конфигурации прямо в консоли через `grep` или `less`.
*   Для генерации отчетов.
*   Для автоматизированного парсинга программными скриптами.

### 8. Значение полей в выводе команды lsmod
Команда выводит три основных столбца данных:
1.  *Module:* Имя загруженного модуля ядра.
2.  *Size:* Объём оперативной памяти, который этот модуль занимает.
3.  *Used by:* Счетчик использования модуля и перечень имен других модулей (зависимостей), которые используют данный модуль.
