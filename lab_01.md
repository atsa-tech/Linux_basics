# Артефакты

## Таблица

| Команда | Назначение | Пример 1 | Пример 2 |
| :---: | :---: | :---: | :---: |
| **hostname** | Выводит или устанавливает имя текущей компьютерной системы. | `hostname` - показать имя компьютера | `sudo hostname my-new-name` |
| **tty** | Выводит имя терминала, подключенного к вводу. | `tty` - узнать имя текущей консоли (например, `/dev/pts/0`) | `tty -s` - вернуть только код ответа (для скриптов) |
| **pwd** | Выводит полный путь от корня к текущему рабочему каталогу. | `pwd` - узнать, в какой папке я нахожусь | `pwd -P` - показать физический путь (без символических ссылок) |
| **whoami** | Выводит имя пользователя, под которым вы сейчас работаете в системе. | `whoami` - узнать имя текущего пользователя | `sudo whoami` - проверка (выведет `root`) |
| **who** | Показывает список всех пользователей, которые сейчас вошли в систему. | `who` - вывести список активных сессий | `who -b` - показать время последней загрузки системы |
| **date** | Выводит или устанавливает текущую дату и время системы. | `date` - посмотреть текущее время | `date "+%Y-%m-%d"` - вывести дату в формате ГГГГ-ММ-ДД |
| **ls** | Выводит список файлов и папок в текущем или указанном каталоге. | `ls -l` - показать список с подробной информацией | `ls -la` - показать все файлы, включая скрытые |
| **mkdir** | Создает один или несколько новых каталогов (папок). | `mkdir scripts` - создать папку с именем `scripts` | `mkdir -p project/src` - создать структуру вложенных папок |
| **touch** | Создает пустой файл или обновляет время изменения существующего. | `touch file.txt` - создать пустой текстовый файл | `touch config.cfg` - создать файл конфигурации |
| **cd** | Изменяет текущий рабочий каталог (переход по папкам). | `cd /var/log` - перейти в папку с логами | `cd ..` - подняться на один уровень выше (назад) |
| **cp** | Копирует файлы или целые каталоги в другое место. | `cp photo.png /tmp/` - скопировать файл в папку `/tmp` | `cp -r docs/ backup/` - скопировать папку `docs` со всем содержимым |
| **mv** | Перемещает или переименовывает файлы и каталоги. | `mv file1.txt file2.txt` - переименовать файл | `mv document.pdf ~/Documents/` - переместить файл в домашнюю папку |
| **rm** | Удаляет файлы или каталоги из файловой системы. | `rm file.txt` - удалить файл | `rm -rf test_folder` - принудительно удалить папку со всем содержимым |
| **rmdir** | Удаляет только пустые каталоги (папки). | `rmdir empty_dir` - удалить пустую папку | `rmdir -p p1/p2` - удалить пустую папку `p2` и её родителя `p1`, если он пуст |
| **find** | Ищет файлы и каталоги в файловой системе по заданным критериям. | `find . -name "*.log"` - найти все лог-файлы в текущей папке | `find /home -type d` - найти все каталоги внутри `/home` |
| **grep** | Ищет указанную строку или регулярное выражение внутри файлов. | `grep "error" app.log` - найти все строки со словом "error" в файле | `grep -i "alice" file.txt` - найти "alice" без учета регистра |
| **cat** | Выводит содержимое файлов на экран или объединяет их. | `cat /etc/hostname` - посмотреть, что написано внутри файла | `cat file1.txt file2.txt` - вывести содержимое двух файлов подряд |
| **echo** | Выводит строку текста в терминал или перенаправляет её в файл. | `echo "Hello World"` - напечатать текст на экране | `echo "test" > file.txt` - записать слово "test" в файл |

# Вопросы и задания

1. После применения команды `chmod +x` мы меняем метаданные файла и даем разрешение на исполнение пользователям, поставив флаг `+x`
2. Debian 13 поддерживаются для следующих архитектур: amd64 (ПК/серверы Intel/AMD), arm64 (64-битная ARM), armhf (32-битная ARM), ppc64el, riscv64 и s390x.
3.   - Netinstall содержит только установщик и базовое ядро, остальное скачивается из интернета. Удобно использовать если ПК подключен к быстрому интернету.
     - Live-image запускается с образа флешки/DVD (iso файла) без установки на жесткий диск. Удобен если нужно протестировать ПК или починить сломавшуюся ОС.
     - Образа DVD содержит огромную базу готовых пакетов и графических оболочек. Обычно устанавливается на компьютерах со слабым/отсутствующим интернетом.
     - Cloud это преднастроенные образы виртуальных дисков без графического установщика. Используется для создания множества ВМ в облаках.
